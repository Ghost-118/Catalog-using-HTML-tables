# Catalog Using HTML Tables

Proyecto que muestra la creación de un catálogo de libros utilizando tablas semánticas en **HTML5**. Su objetivo principal es estructurar adecuadamente la información en filas y columnas, aprovechando la separación de secciones de datos y resúmenes al final de la tabla mediante el uso del elemento `<tfoot>`.

---

## 🚀 Características

- **Estructura Semántica de Tablas:** Organización clara dividida en encabezado (`<thead>`), cuerpo (`<tbody>`) y pie de tabla (`<tfoot>`).
- **Resumen de Datos:** Uso del atributo `colspan` en la sección `<tfoot>` para combinar celdas y presentar el total de libros catalogados.
- **Diseño Adaptativo Básico:** Configuración del metatag `viewport` para asegurar una correcta visualización en dispositivos móviles.
